# Refrain

macOS で撮ったスクリーンショットを自分のドメインにアップロードし、共有用の URL を返す個人用ツール。

## Language

**Refrain**:
このスクリーンショット共有システムのプロダクト名。アップロードを受ける側と、Mac で撮影して送る側の両方を指す。
_Avoid_: gyazo-remake（取り込み前の独立リポジトリの旧名）、スクリーンショット共有システム

**Upload Token**:
アップロードを許可するための、利用者ひとりにつき 1 つの共有シークレット。持っていれば誰でもアップロードできる。
_Avoid_: API key, password

**Image URL**:
アップロードした画像を指す、恒久的な公開 URL。知っていれば誰でも閲覧できる。
_Avoid_: share link（Phase 2 で、期限付き・取り消し可能な別概念として使う予定のため）
